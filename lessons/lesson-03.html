Return current: every signal is a loop

If you remember one idea from this course, make it this one. Current always flows in a loop, and the half of the loop you don't draw (the return path) decides your noise, your EMI and your signal integrity.

  • What a slot or split in a plane does to a fast signal, and how to fix it
  • Why a thin dielectric to the plane keeps fields (and crosstalk) tight
  • What happens to the return current when a signal changes layers

3.1 Current always flows in loops

On a schematic you draw a wire from a driver to a receiver, and a ground symbol at each end. But charge cannot pile up anywhere, so every bit of current that flows out along the signal trace must flow back to the driver. The ground symbols hide the second half of the loop.

The loop formed by the signal and its return has an area. Loop area sets the inductance (lesson 1), how strongly the loop radiates (it is a small loop antenna) and how strongly it picks up fields from neighbours. Small loop = good. A ground plane is useful because it lets the return current flow wherever it needs to in order to keep the loop small.

3.2 Where does the return current go on a plane?

Current takes the path of least impedance: Z = R + jωL. At low frequency, resistance dominates and the return current spreads out across the plane, taking the shortest, widest route between the two ground vias. At high frequency, inductance dominates and the lowest-inductance route is the one that makes the loop smallest: directly underneath the signal trace, whatever path the trace takes.

Drag the two route handles, change the frequency, and move the slot around (drag it) to see this.

Rule of thumb

Never route a fast signal across a slot, split or void in its reference plane. If you can't avoid it, give the return current a bridge right at the crossing: a stitching capacitor (10–100 nF) between the two planes, or a copper bridge if both sides are ground (Sierra §3.5.5). Routing around the gap is better still.

Why the slot is so bad at high frequency

The return current wants to be under the trace. When it reaches the slot it has to go around the end. That turns a loop with an area of "trace length × 0.2 mm" into one that can be several cm². Three things get worse at once: the loop radiates (EMI scales with area × f²), the extra inductance is an impedance bump that reflects fast edges, and the detouring current flows under other traces nearby, causing crosstalk. Slots appear by accident far more often than by design: a row of vias with antipads that merge, a plane split for another rail, or a cut-out for a connector.

3.3 How tightly does the return hug the trace?

For a trace at height H above a plane, the high-frequency return current density across the plane follows a simple curve: J(x) ∝ 1 / (1 + (x/H)²). Half the current flows within ±H of the centreline. Connection to crosstalk

The value of this curve under the neighbour, 1/(1+(D/H)²), is the same coupling coefficient Jones gives for crosstalk (lesson 1.3). Return currents that overlap means fields that overlap. That is why Sierra wants signal layers tightly coupled to their plane (<10 mil ≈ 0.25 mm, §4.1.7). A thin dielectric shrinks every loop on the board.

3.4 Changing layers: the return has to change layers too

When a signal goes through a via to another layer, its reference plane often changes too. The return current then has to get from one plane to the other, near the via. If the only connection between the planes is far away, the return current takes a detour (more loop area, more inductance) or crosses as displacement current through the plane-to-plane capacitance, which spreads noise across the whole board.

Rule of thumb

Whenever a fast signal changes layers between two ground references, put a ground stitching via right next to the signal via (within ~1 mm; for diff pairs, place them symmetrically). If the new reference is a power plane, you need a stitching capacitor instead. Better still, plan the stackup so fast signals only ever reference ground (Sierra §3.5.5, §7.3.1.7).
