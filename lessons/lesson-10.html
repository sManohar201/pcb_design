Lesson 10 · High-speed signals

Vias

A via is a plated hole joining layers, and almost every net on a carrier board uses some. To a DC current it's a tiny resistor. To a fast edge it is a short, badly matched transmission line, often with an unused stub hanging off it. This lesson covers via types, what a via does to a signal, how much current it carries, and how via size decides whether a fine-pitch BGA can be routed at all.

You'll learn

  • How pad, antipad, drill and return vias set a via's impedance
  • How many vias a high-current connection needs
  • Why BGA pitch drives layer count and HDI technology

10.1 Via types and the stub problem

A standard through via is drilled through the whole board. If your signal only goes from L1 to L3, the rest of the barrel below L3 is a stub: an open-ended piece of line that resonates when it is a quarter-wavelength long, removing that frequency from the signal (Sierra §2.3.4). Fixes cost money: back-drilling removes the stub with a larger drill from the other side; blind and buried vias (and laser-drilled microvias, typically spanning one layer) never create it.

Rule of thumb

Keep the stub's quarter-wave resonance well above the signal's Nyquist frequency (a common target is ≥ 3×). For 8–16 Gb/s links that means routing fast signals to layers near the bottom when the via starts at the top (short stub), back-drilling, or using blind vias. Mind the aspect ratio: through-holes up to ~10:1 (board thickness : drill) and microvias ~0.75:1 (Sierra §4.1.2).

10.2 A via as a discontinuity: pads, antipads and return vias

Each pad sitting inside a plane's clearance hole (antipad) is a small capacitor to that plane. The barrel and its return path form an inductance. Too much capacitance (big pads, small antipads) gives a low-impedance dip; too much inductance (long barrel, distant return via) gives a bump. A good high-speed via balances the two near the line impedance.

Rule of thumb

For fast signals: remove unused (non-functional) pads on inner layers, size antipads to bring the via close to the line impedance (without making the plane "Swiss cheese": lesson 5.4), and place a ground return via within ~1 mm of every signal via that changes reference (lesson 3.4).

10.3 How much current can a via carry?

Sierra's trick (§7.4.3.2): unroll the via barrel. It becomes a "trace" whose width is the hole's circumference (π × drill) and whose thickness is the plating (≈20–25 µm). Apply the IPC-2221 trace formula from lesson 1. Their example: a 0.2 mm (8 mil) drill carries ~0.8 A for a 5 °C rise. Jones: "for high currents, use multiple vias."

10.4 BGA fanout: why pitch drives layer count

A ball-grid array's inner balls can only escape through vias, and their traces must squeeze between the vias of the outer rows. Whether one trace fits between two vias depends on pitch, via pad size and the fab's trace/space. That decides how many rows each layer can escape, and so how many layers you need. On a Jetson carrier the module connector isn't a BGA, but PCIe switches, USB hubs and Ethernet PHYs often are.
